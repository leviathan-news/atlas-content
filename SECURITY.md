# Reporting security or privacy concerns

Do not report vulnerabilities, credentials, personal data, private allegations,
or partner-sensitive material in a public pull request. Report security concerns
privately to [security@leviathannews.xyz](mailto:security@leviathannews.xyz).

This repository contains no executable contribution path. A report about an
Atlas fact or editorial correction belongs in a scoped pull request only when it
is safe to make the proposal public.
